# Витрина исследовательской лаборатории

Общая база связывает гипотезы с критериями опровержения, протоколы и состояния прогонов,
измерения с источниками, математические выкладки и решения с их основаниями.

**Публикации Андрея** — 22 открыто представленные статьи и препринта Андрея Веприкова
и соавторов, 86 тезисов, ссылки на оригиналы и места публикации. Это краткие пересказы
аннотаций и отдельных частей введения. Объём разбора указан в каждой карточке.
Статус препринта отделён от конференции или журнала.

**Другие исследования** — 8 статей других авторов и 24 тезиса по темам примеров:
LoRA, AdaLoRA, MeZO, Shampoo, QSGD, Performative Prediction, разогрев и SOAP.
Пересказы основаны на аннотациях arXiv, ссылки и объём разбора сохранены в карточках.

**Демо-лаборатория** — вымышленный учебный проект: 77 записей, включая 16 научных
утверждений, 20 учебных статей и 51 тезис. Его прогоны и числа не являются результатами
публикаций автора. Всего в витрине 50 статей и 161 тезис. Приватная база не подключена.

Восемь примеров сформулированы как общие исследовательские вопросы, без названий методов.
Каждый открывает подборку: сначала работа лаборатории с аннотацией и тезисами,
затем две статьи по теме. Подборки заданы в `questions` манифеста и помечены в интерфейсе.
Выделенная работа сохраняет тип статьи: вымышленные проекты или прогоны для неё не создаются.
Произвольный вопрос по-прежнему обрабатывает поисковый индекс браузера. На ранжирование
живого MCP демонстрационные подборки не влияют.

## Открыть

Сервер не нужен, сайт статический:

```bash
open index.html          # macOS
xdg-open index.html      # Linux
```

## Поставить на свою базу

Витрина читает четыре файла данных и больше ничего не знает об источнике:

| Файл | Что в нём |
|---|---|
| `data/base-snapshot.js` | `window.LAB_BASE` — записи: проекты, утверждения, прогоны, измерения, правила, термины |
| `data/library-snapshot.js` | `window.LAB_LIBRARY` — статьи и разобранные из них утверждения |
| `data/atlas-tree.js` | `window.LAB_TREE` — дерево разделов с аннотациями: по нему отвечают широкие запросы |
| `data/atlas-public.js` | `window.LAB_ATLAS_DATA` — реестр инструментов лаборатории |

## Обновить публикации

Список и проверенные источники хранятся в `data/publications.json`. После его изменения
в корне репозитория выполните:

```bash
python3 scripts/build_publications.py
python3 -m pytest tests/test_showcase_demo.py
node tests/test_showcase_publications.cjs
```

Сборка добавляет только этот открытый список, сохраняет учебные записи и не читает
приватный Atlas или MCP. Повторный запуск не дублирует статьи. Список сверён
16-09-2026 по arXiv, ORCID, OpenReview и страницам издателей. Препринт и его журнальная
версия представлены одной карточкой; русская и английская версии также не дублируются.

Для отдельной приватной установки можно собрать эти файлы из своей базы в той же схеме.
Не публикуйте их вместе с демоверсией. Схема видна в файлах этой сборки.

## Живой поиск

В публичной сборке поиск идёт по публикациям и учебному набору в браузере. Метка `window.LAB_DEMO`
блокирует все обращения к живому MCP, включая проверку доступности и список инструментов.
Даже доступный на компьютере приватный прокси не используется.

Сама лаборатория использует MCP-службу `lab-knowledge`: e5-эмбеддинги, BM25 через RRF,
расширение по графу связей и переранжирование кросс-энкодером. Порядок ответа задаёт
кросс-энкодер, а не совпадение слов — поэтому в ответе подсвечивается не совпавшее слово, а
то, чем утверждение закрыто.
