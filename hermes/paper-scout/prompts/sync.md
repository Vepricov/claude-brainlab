Полная сверка локальной библиотеки с AlphaXiv. Локальная библиотека — главная,
AlphaXiv — её отражение.

ПОЧЕМУ ПРОСТО. `save_papers_to_folder` идемпотентен: на статью, которая в папке уже
есть, он отвечает `already_in_folder` и ничего не меняет (проверено 04-09-2026).
Поэтому сравнивать состояния НЕ НУЖНО — достаточно отправить каждой папке её полный
локальный список, а ответ вызова сам скажет, что добавилось. Не пытайся звать
`list_library(include_papers=true)`: он отдаёт больше ста килобайт и обрезается.

КАК РАБОТАТЬ. Одна команда в терминале и вызовы MCP. НЕ ПИШИ скриптов, НЕ качай
страниц, НЕ проверяй чужие скрипты. Инструмент не ответил — скажи в отчёте.

ШАГ 1. Одна команда, она же пишет опись:
    python3 ~/paper-agent/local_inventory.py --json
Прочитай `~/paper-agent/state/local_inventory.json` через read_file. Формат:
`{"folders": {"Top/Sub": {"folder_id": "...", "arxiv_ids": [...]}}, "unmapped": [...]}`.

ШАГ 2. По КАЖДОЙ папке из `folders` — один вызов со ВСЕМ её списком:
    save_papers_to_folder(folder_id=<folder_id>, paper_ids_or_urls=<весь arxiv_ids>)
Считай в ответе, у скольких статей `status` не равен `already_in_folder` — это и есть
добавленные. Папки обходи по порядку, ни одну не пропускай.

ШАГ 3. Один вызов: list_library(include_papers=false). Для каждой статьи из папки
«Want to read» (её содержимое посмотри вызовом
`list_library(paper_ids_or_urls=[...])`, если понадобится) проверь командой:
    grep -rl "<arxiv_id>" ~/brainlab-operon/Reading/
Карточки нет — заведи одной командой, папку возьми из описи:
    python3 ~/paper-agent/make_cards.py --status Очередь --no-digest \
        --pick "<arxiv_id>|<Тема>|<Top/Sub>|<две-три фразы о сути>"
Из «Want to read» ничего не удаляй.

ЗАПРЕТЫ. Не создавать папок: `unmapped` просто перечисли. Не трогать
`My publications` и `Private Papers`. Ничего не удалять. Субагентов не запускать.

ОТЧЁТ — числа о сделанном:
· строка на каждую папку, куда что-то реально добавилось: `<папка>: +N`;
· `всего добавлено: N`;
· какие карточки завёл из «Want to read»;
· какие папки не сопоставлены.
Если везде было `already_in_folder` — ровно одна строка: «библиотеки совпадают, N статей».
