# 📚 example-project — литература

Разбираемые статьи проекта. Ссылки ведут в разборы темы `<направление>/<тема>/literature/` — оттуда можно ссылаться на статью из любой заметки проекта.

## Базовые
- [[<направление>/<тема>/literature/Название|Название]] — чем важна для проекта.

## Смежное
- [[<направление>/<тема>/literature/Название|Название]] — краткое пояснение.

## К разбору
- Название — ([arXiv](https://arxiv.org/abs/ID)). Ещё не в библиотеке → добавить через `paper-ingest`, затем заменить на `[[<направление>/<тема>/literature/...]]`.

> Новые статьи: сначала добавить в `<направление>/<тема>/literature/` (skill `paper-ingest`), затем сослаться здесь как `[[<направление>/<тема>/literature/...]]`.
