# Server Hygiene — не захламлять общие серверы (ALL agents, ALL sessions)

Серверы (shkodnik_opt, brain_lab, vv_h200, do-vpn и др.) — ОБЩИЕ и с ограниченным диском.
Корень `/` маленький (напр. shkodnik_opt: `/` всего 133G, легко забивается до 100% и тогда НИКТО
не может писать). Агенты обязаны не оставлять мусор.

## HARD RULES
1. **НЕ писать во временное на корне `/`.** `/tmp` и `/var/tmp` живут на корневом ФС — большие
   временные файлы туда = риск забить `/` до 0. Экспериментам ставить свой скретч на `/home`:
   ```bash
   export TMPDIR=$HOME/tmp                 # не /tmp
   export HF_HOME=$HOME/.cache/huggingface # HF-модели на /home (там место), не на /
   export TORCHINDUCTOR_CACHE_DIR=$HOME/.cache/torchinductor
   mkdir -p "$TMPDIR"
   ```
2. **Убирать за собой после прогона.** Свой скретч/чекпоинт-временное/`__pycache__`/распаковки
   удалять по завершении эксперимента. Логи держать компактными (одна сводка + `<NAME>_DONE`),
   не плодить десятки мегабайтных логов в `$HOME`.
3. **Кеши — регенерируемы, чистить периодически.** `pip cache purge`, `uv cache clean`,
   `conda clean -a`, старые HF-снапшоты. Не давать `~/.cache` пухнуть до сотен ГБ.
4. **НИКОГДА не трогать чужое.** Удалять только СВОИ файлы (свой `$USER`). Чужие процессы, чужой
   `/tmp/<other_user>`, чужие данные — не трогать даже при нехватке места. Нехватку решать чисткой
   своего следа + системных кешей (`apt-get clean`, `journalctl --vacuum-size=`), а системную
   политику `/tmp` (авто-чистка старого) менять только с ведома владельца сервера.
5. **Перед тяжёлым прогоном проверить место:** `df -h /` и `df -h /home`. Если `/` близко к 100% —
   не запускать во `/tmp`, увести всё на `/home` и/или сообщить пользователю.

## Диагностика «нет места» (df 100%)
```bash
sudo du -xhd1 / | sort -rh | head          # виновники на КОРНЕ (-x не лезет в /home)
sudo du -sh /tmp /var/log /var/cache/apt   # частые виновники корня
du -sh ~/.cache/* | sort -rh | head        # свой кеш (обычно на /home)
```
Свой мусор — чистить; чужой/системную политику — только по согласованию.

## Durable (shkodnik_opt, 09-07-2026)
Поставлен `/etc/cron.daily/tmp-hygiene`: ежедневно удаляет из `/tmp` записи старше 10 дней (кроме
сокетов `.X11-unix` и т.п.). Так `/` больше не забивается заброшенным temp. Подробности и разбор
инцидента: Obsidian `general/servers.md`.
