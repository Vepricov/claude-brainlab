# Теги разбора

Теги нужны, чтобы находить работы поперёк тем: `tag:muon tag:convergence-analysis` собирает
теорию Muon из `muon-convergence-theory`, `markovian-optimization` и `preconditioning-curvature`
сразу. До 20-10-2026 у 737 из 746 разборов стоял один тег — имя темы, то есть то же, что и
папка, — и искать по ним было нечего.

Правила:

- первым всегда тег темы (имя папки `<тема>`), его ставит каркас;
- дальше от 3 до 7 тегов ТОЛЬКО из списка ниже, без своих слов. Нужного нет — не выдумывать,
  а предложить строкой в отчёте: словарь растёт решением, а не каждым разбором;
- ставить то, о чём статья, а не то, что в ней упомянуто. Работа про LoRA, где сравнивают с
  Adam, получает `lora`, но не `adam`;
- ровно один тег вида работы: `theory`, `method`, `empirical-study`, `benchmark`, `survey`,
  `system`.

## Вид работы

| тег | когда |
|---|---|
| `theory` | главное — доказательства, оценки, анализ |
| `method` | предлагают новый алгоритм, архитектуру или приём и проверяют его |
| `empirical-study` | ничего нового не предлагают, измеряют и объясняют поведение |
| `benchmark` | набор задач, оценка, сравнение многих методов |
| `survey` | обзор, учебник, блог-разбор области |
| `system` | инженерная система: ядра, распределённый фреймворк, отчёт о модели |
