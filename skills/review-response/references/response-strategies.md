# Compatibility entrypoint: response strategy

This filename is retained for legacy `rebuttal-writer` integrations. Use the Response Strategist contract in `agent-prompts.md`, the stance taxonomy in `concern-ledger.md`, and the case-specific rules in `hard-cases.md`.

For each atomic concern, choose from `correct_misunderstanding`, `clarify`, `defend`, `concede_local`, `narrow_claim`, `promise_revision`, `run_experiment`, or `cannot_resolve`. Choose by scientific evidence and decision relevance, not by rhetorical convenience.

The response order is direct answer, evidence with an exact anchor, concrete manuscript or experiment action, then residual limitation. Keep the submitted method distinct from local fixes and core revisions. Never use a changed core method to claim that the original concern is resolved.
