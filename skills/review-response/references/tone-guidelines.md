# Compatibility entrypoint: tone

This filename is retained for legacy `rebuttal-writer` integrations. The canonical style gate is G5–G6 in `quality-gates.md`.

Write concise scientific prose. Lead with the answer. Use one acknowledgment per reviewer thread, not one per bullet. Remove repeated thanks, generic praise, score requests, reviewer blame, promotional language, and claims that exceed the evidence level.

Disagree by naming the exact premise, submission anchor, and verified consequence. Concede local errors directly. Never call a concern fully resolved when the reviewer marks it partial or when the decisive evidence comes from a core revision.
